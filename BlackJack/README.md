# Blackjack

A simplified single-player Blackjack game built with **HTML**, **CSS**, and **JavaScript**, featuring random card draws and automatic win/bust detection.

## Preview

Click "Start Game" to deal two random cards and see your running sum. Click "New Card" to draw another card — the game automatically detects if you've hit Blackjack (21) or gone bust (over 21).

## Features

- Random card generation (values 1-10, with face cards treated as 10 and Aces as 11)
- Live running sum display, updated after every card drawn
- Automatic game-state detection: "keep playing," "Blackjack!", or "you're out"
- Player object tracking name and chip count
- Clean dark casino-style theme with custom Google Font (`Kameron`) and a background image

## Tech Stack

- HTML5
- CSS3 (background images, custom fonts, hover states)
- JavaScript (objects, arrays, conditional logic, random number generation, DOM manipulation)
